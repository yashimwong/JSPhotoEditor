# JSPhotoEditor
A simple photo editor made purely using JavaScript, HTML and CSS.

# Current Functionality
- Exposure
- Contrast
- Grayscale
- Saturation
- 90-degree rotation
- Horizontal and vertical flipping
- Undo and redo (up to 50 editing operations)
- Blur
- Sharpen
- Color Filter
- Shape Drawing
- Shape color and opacity controls
- PNG, JPEG and WebP Export
